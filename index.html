                        📘 Справка

                        Калькулятор Сметчика v5.4 (web) — инженерные расчёты для сметного отдела.

                        Разделы:

                        • Металлопрокат — масса по геометрии
                        • Сортамент ГОСТ — массы 1 м из справочника
                        • Профили ГКЛ — каталог профилей и перфолента
                        • Покраска — площадь + расход краски
                        • Пескоструй — расход абразива по ISO 8501-1
                        • Нормы АКЗ — библиотека ЛКМ
                        • Крепёж — болты, гайки, саморезы и т.д.
                        • Изоляция — объём изоляции труб
                        • Расчёт АКЗ — загрузка норм из Excel
                        • Сварка — расход электродов/газа
                        • Калькулятор — обычный + история

                        Особенности: приём точки и запятой, копирование результатов по клику, история в localStorage, работа offline.
